# 22. Sources

Every chapter ends with the sources it used. This chapter groups the main ones by topic and says how far to trust each.

**How to weigh them.** Patch 5.0 came out on September 29, 2026, and patch 5.01 on October 8, 2026. CD PROJEKT RED's own notes describe the systems but publish almost no numbers, so nearly every 5.0 value in this book comes from community databases and guides written in the first days after release. Item, set and quest data mostly come from pre-5.0 wikis, which is fine as long as no 5.0 note changes them, and none does. Where sources disagree, the chapters give both versions. For the audited mechanics, [chapter 19](19-the-maths.md#file-evidence-and-reproducibility) records direct file evidence from build `5.0.0.1048522`. A tooltip describes intended behavior; a controlled test can resolve a conflict with the implementation.

**Era tags:** **5.0** = published on or after September 29, 2026. **Pre-5.0** = older, or undated wiki pages.

## What's missing

The local file audits now supply the base crit, Toxicity and Stamina values; the Toxicity budget (Acquired Tolerance, Metabolic Control, Manticore armor, decoctions, Toxicity damage); Euphoria, Delayed Recovery, Fast Metabolism and Volatile Compound; combat Stamina; the strong-attack and armor pipeline; the whole poison line; Undying, Whirl, Rend, Deadly Precision and Attack Is the Best Defense; the branch passives; Conductors of Magic and Magic Sensibilities; and the sources of skill points. They also correct the old crit lower bounds, the Wolven Three Strikes priority and the Manticore plan's Toxicity budget and Delayed Recovery pick. [Chapter 19](19-the-maths.md#file-evidence-and-reproducibility) records the installed build, definition paths, script locations and validation limits. The highest-priority remaining questions are how Cat School Techniques' crit damage combines with the base crit bonus, attack timings, how many recipes a playthrough can learn, New Game+ Delayed Recovery, per-enemy poison resistance, and the attainable skill-point total. A published Remastered Viper build was not found in the original source review.
